Question 1(a)
How do you declare an array of structures?

An array of structures is declared by first defining a structure type and then declaring an array of that type.

Cstruct Student {
    char name[50];
    int roll;
    float marks;
};

/* Declare an array that can hold 30 Student structures */
struct Student class[30];

/* Declare and initialize three Student structures at once */
struct Student s[3] = {
    {"Alice", 101, 92.5},
    {"Bob",   102, 88.0},
    {"Carol", 103, 95.5}
};
Access members with class[i].roll or s[i].name. The array itself occupies contiguous memory; each element is a complete structure instance.
Question 1(b)
Explain the purpose of preprocessor directives in C.

Preprocessor directives are instructions processed before actual compilation. They begin with # and are handled by the C preprocessor (cpp).

DirectivePurpose
#includeInsert header file contents (e.g., <stdio.h>)
#defineCreate macros / symbolic constants
#ifdef / #ifndef / #endifConditional compilation
#pragmaCompiler-specific instructions
#undefRemove a macro definition

They enable modular code, portability, compile-time configuration and avoid repeated typing of constants.

Question 1(c)
What is type casting? Give an example.

Type casting is the explicit conversion of a value from one data type to another.

Cint a = 7, b = 2;
float result = (float)a / b;   /* Cast forces floating-point division → 3.5 */
printf("%.1f", result);

Syntax: (target_type) expression. Without the cast, integer division truncates; the cast forces floating-point arithmetic.

Question 2(b)
Write a recursive function to find the factorial of a given number.
C#include <stdio.h>

long factorial(int n) {
    if (n == 0 || n == 1)
        return 1;                 /* Base case: 0! = 1! = 1 */
    return n * factorial(n - 1);  /* Recursive step: n! = n * (n-1)! */
}

int main() {
    int num;
    printf("Enter a non-negative integer: ");
    scanf("%d", &num);
    if (num < 0) {
        printf("Factorial not defined for negative numbers.\n");
        return 1;
    }
    printf("Factorial of %d = %ld\n", num, factorial(num));
    return 0;
}
Time complexity O(n), space O(n) due to call stack. For large n prefer iterative or big-integer libraries.
Question 2(c)
Discuss Rules for C identifiers.
  1. Must begin with a letter (A–Z, a–z) or underscore _.
  2. Subsequent characters may be letters, digits (0–9) or underscore.
  3. No spaces, special symbols (@, #, $, %, etc.) allowed.
  4. Case-sensitive: Count ≠ count.
  5. Cannot be a C keyword (int, while, return …).
  6. Length: first 31 characters significant in most compilers (C99+ allows longer).
  7. Should be meaningful (good practice, not a language rule).

Valid: _count, sum2, max_value
Invalid: 2sum, max-value, float, my var

Question 2(d)
What is pointer? Explain the difference between call by value and call by reference.

A pointer is a variable that stores the memory address of another variable.

Cint x = 10;
int *p = &x;   /* p stores the memory address of x */
printf("%d", *p); /* Dereference: follow the address to get the value 10 */
AspectCall by ValueCall by Reference
What is passedCopy of the valueAddress (pointer) of the variable
Original changed?NoYes
Syntaxvoid f(int x)void f(int *x)
Call sitef(a);f(&a);
C/* Call-by-value: receives copies; original variables stay unchanged */
void swap_val(int a, int b) {
    int t = a; a = b; b = t;
}

/* Call-by-reference: receives addresses; changes affect the originals */
void swap_ref(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}

Question 3(a) — Part (ii)
Write a C program to swap two numbers using pointers.
C#include <stdio.h>

void swap(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}

int main() {
    int a, b;
    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);
    printf("Before swap: a = %d, b = %d\n", a, b);
    swap(&a, &b);
    printf("After  swap: a = %d, b = %d\n", a, b);
    return 0;
}

Question 3(b) — Part (i)
Explain how arrays are declared, initialized and processed in C.

Declaration

Cint arr[5];               /* Size must be a compile-time constant */
float marks[100];

Initialization

Cint a[5] = {10, 20, 30, 40, 50};

int c[5] = {1, 2};        /* Remaining elements are zero-filled */

Processing — almost always with loops:

C/* Traverse the array and print each element */
for (int i = 0; i < 5; i++)
    printf("%d ", a[i]);

int sum = 0;
for (int i = 0; i < 5; i++)
    sum += a[i];
Array name decays to pointer to first element. Bounds are not checked by the language — out-of-range access is undefined behaviour.
Question 3(b) — Part (ii)
Write a program to sort an array of integers.

Classic Bubble Sort (simple & exam-friendly):

C#include <stdio.h>

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int n;
    printf("Enter size: ");
    scanf("%d", &n);
    int a[100];
    printf("Enter %d elements: ", n);
    for (int i = 0; i < n; i++)
        scanf("%d", &a[i]);

    bubbleSort(a, n);

    printf("Sorted array: ");
    for (int i = 0; i < n; i++)
        printf("%d ", a[i]);
    printf("\n");
    return 0;
}
flowchart TD A["Start with unsorted array"] --> B["Outer pass: i from 0 to n-2"] B --> C["Inner pass: j from 0 to n-i-2"] C --> D{"Is arr j greater than arr j+1?"} D -->|Yes| E["Swap the two elements"] D -->|No| F["Keep order"] E --> G{"More j?"} F --> G G -->|Yes| C G -->|No| H{"More outer passes?"} H -->|Yes| B H -->|No| I["Array is now sorted"]
Question 3(c) — Part (i)
Explain the syntax of creating function in C in detail, including function prototype, definition and calling.

1. Function Prototype (declaration) — tells the compiler the signature before use:

Creturn_type function_name(parameter_list);

2. Function Definition — the actual body:

Creturn_type function_name(parameter_list) {
    /* Function body: statements that perform the work */
    return value;   /* Required only when return type is not void */
}

3. Function Call

Cvariable = function_name(arguments);

Complete example:

C#include <stdio.h>

/* Function prototype: informs the compiler of the signature */
int add(int, int);

int main() {
    int result = add(12, 30);   /* Function call with actual arguments */
    printf("%d\n", result);
    return 0;
}

/* Function definition: the actual implementation */
int add(int x, int y) {
    return x + y;
}
Question 3(c) — Part (ii)
Write a C program using functions to find prime numbers given as input.
C#include <stdio.h>
#include <math.h>

/* Helper function: returns 1 (true) if n is prime, otherwise 0 */
int isPrime(int n) {
    if (n <= 1) return 0;
    if (n == 2) return 1;
    if (n % 2 == 0) return 0;
    for (int i = 3; i <= sqrt(n); i += 2) {
        if (n % i == 0) return 0;
    }
    return 1;
}

int main() {
    int num;
    printf("Enter a positive integer: ");
    scanf("%d", &num);
    if (isPrime(num))
        printf("%d is a prime number.\n", num);
    else
        printf("%d is not a prime number.\n", num);
    return 0;
}
The function can be reused to print all primes in a range by looping over candidates and calling isPrime.

Note (i)
Dynamic Memory Allocation

Memory allocated at run-time from the heap using library functions in <stdlib.h>:

  • malloc(size) — allocates uninitialized block
  • calloc(n, size) — allocates zero-initialized array
  • realloc(ptr, newsize) — resizes previously allocated block
  • free(ptr) — releases memory back to heap
Cint *p = (int*)malloc(5 * sizeof(int));
if (p == NULL) { /* Always check: allocation may fail */ }
/* Now safely use p[0] through p[4] */
free(p);   /* Release the memory when finished */

Essential for flexible data structures (linked lists, dynamic arrays). Always check for NULL and free to avoid leaks.

Note (ii)
Loops in C Language

Three primary looping constructs:

LoopWhen to use
forKnown number of iterations
whileCondition checked before entry
do-whileBody must run at least once

All support break, continue and nested loops. Infinite loop: for(;;) or while(1).

Typical choice frequency in exam programs

Note (iii)
File operation in C

Core steps:

  1. Declare FILE *fp;
  2. fp = fopen("name", mode);
  3. Read/Write with fscanf, fprintf, fgets, fputs, fread, fwrite
  4. fclose(fp);

Always test fp != NULL. Modes already listed in Q1(g). Binary mode preferred for non-text data.

Note (iv)
Data types in C

Primary categories:

  • Basic: int, char, float, double, _Bool
  • Derived: arrays, pointers, structures, unions, functions
  • Enumeration: enum
  • void: no value / generic pointer

Modifiers: signed, unsigned, short, long. Size is implementation-defined; use sizeof and fixed-width types from <stdint.h> when portability matters.
